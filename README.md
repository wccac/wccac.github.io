# 檀晷 TÁN GUǏ

檀香品牌「檀晷」的移动端数字品牌体验。界面以木纹档案、时间刻度和复古纸张为核心视觉语言，展示 15、30、45 分钟三个产品品类，并支持产品横向循环浏览。

## 在线预览

[https://wccac.github.io/](https://wccac.github.io/)

## 本地运行

```bash
pnpm install
pnpm run dev
```

## 发布方式

提交到 `main` 分支后，GitHub Actions 会完成运行时校验、TypeScript 检查、Vite 构建，并将 `dist/client` 自动部署到 GitHub Pages。
